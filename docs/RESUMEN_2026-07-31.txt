2. SHEETS — ESTRUCTURA EXACTAMENTE COMO LA TIENES
================================================================================

CONFIG
  Headers: TIPO | VALOR_ID | DESCRIPCION
  - Filas: Maestros M01-M09, Periodo 2026-07, Categorías de competencias

ALUMNOS
  Headers: AlumnoID | NombreCompleto | Grupo | Grado | MaestroID
  - 195 alumnos (reales + 91 reservas "Disponible N")
  - Formatos de ID: 1.X, 2.X, 3.X, 4.X, 5.X, 6.X, 1.Xs, 2.Xs, 3.Xs

EVALUACIONES
  Headers: ID_Registro | CicloEscolar | Mes | AlumnoID | MaestroID |
           Calificacion_Numerica | Participacion | Autogestion |
           Colaboracion | Pensamiento_Critico | Asistencia_Porcentaje |
           Tareas_Entregadas | Observaciones | Indice_Desempeno |
           Nivel_Riesgo | Semaforo | FechaRegistro
  - 17 columnas (backend escribe TODAS, incluyendo las calculadas)

MAESTROS_AUTH
  Headers: MaestroID | PasswordHash | Salt | Activo | UltimoAcceso
  - 16 cuentas: M01-M09, G01-G05, ADM, DIR
  - Password único con variante: wundtM01, wundtM02, ..., wundtADM, wundtDIR

ACCESOS_PADRES
  Headers: AlumnoID | PINHash | Salt | TutorNombre | TutorEmail |
           TutorTelefono | Activo | FechaAlta
  - 195 filas (PINs para todos los alumnos)
  - PINs en plano: 4 dígitos, hasheados con SHA-256

BACKUP_LOGS
  Headers: Fecha | Payload | Estado
  - Auditoría de todos los POST

4. FUNCIONES DE ADMINISTRACIÓN (en lib_auth.gs)
================================================================================

Para correr en Apps Script → seleccionar función → ▶ Ejecutar:

  resetPasswordMaestro("M03", "wundtM03", true)
    → Resetea password de un maestro

  seedMaestrosCompleto(true)
    → Crea/actualiza los 16 maestros con variante wundtXXX
    → true = sobreescribe / false = solo crea faltantes

  seedPINsPadres(true)
    → Genera PINs para todos los alumnos que aún no tienen
    → true = regenera todos / false = solo faltantes

  diagnosticoSheets()
    → Imprime estado de todas las hojas (válido Headers, conteos)

  diagM03()
    → Diagnóstico específico de M03 (hash vs candidato)

  listarPINsActivos()
    → Lista los alumnos con PIN (no muestra PIN en plano)

  _resetM03Ahora()
    → Wrapper de ejemplo que llama resetPasswordMaestro('M03','wundtM03',true)
    → Útil cuando Apps Script no detecta los argumentos

  _resetTodosConVariante()
    → Resetea los 16 con la variante wundtXXX

6. BUGS CONOCIDOS (trabajados pero conviene saber)
================================================================================

1. CACHÉ AGRESIVA DEL NAVEGADOR
   Síntoma: el navegador sigue ejecutando JS viejo aunque cambies el código
   Solución: Ctrl+Shift+R o agregar ?v=2 al tag <script>

2. ARGUMENTOS EN APPS SCRIPT
   Síntoma: funciones que toman argumentos reportan "falta parámetro"
   Solución: usar función envoltorio (ej. _resetM03Ahora) sin argumentos

3. SALT DUPLICADO
   En lib_auth.gs línea 14: `return bytes + bytes;` duplica el UUID
   Esto NO es bug crítico (el hash sigue siendo válido), pero el salt
   tiene menos entropía de la deseada. Para producción real,
   reemplazar por:
     const bytes = Utilities.getUuid().replace(/-/g, '');
     const bytes2 = Utilities.getUuid().replace(/-/g, '');
     return bytes + bytes2;
   Bajo prioridad: ningún login falla por esto.

4. UI.JS: state.cicloEscolar hardcoded
   En modelos.js línea 22: `cicloEscolar: '2026-07'`
   Funciona porque coincide con CONFIG, pero idealmente leer de CONFIG.
   Para cambiar el ciclo a "2026-08" o "2027-07", editar esa línea.

5. ALUMNOS DUPLICADOS (3.1s aparece dos veces en "Disponible")
   En tu hoja actual hay "3.1s" listado como "Disponible" pero también
   "AZUARA ESPINOZA DULCE REGINA" como 3.1s. Verifica que no haya
   duplicados reales. Si los hay, eliminar las filas duplicadas.
