BUGS ENCONTRADOS Y ARREGLADOS HOY
================================================================================

BUG 1 — "Identifier 'SHEETS' has already been declared"
  Causa: Habías hecho copias de seguridad de los archivos .gs dentro del mismo
         proyecto Apps Script. Las "Copia de Code", "Copia de lib_sheets", etc.
         declaraban const SHEETS y colisionaban con las del archivo original.
  Solución aplicada: Eliminaste las copias duplicadas desde el panel de Apps Script.

BUG 2 — Portada daba 404 (portadaeval.png no existía)
  Causa: Referencia a imagen decorativa que nunca subiste.
  Solución aplicada: Reemplazada por SVG embebido con patrón decorativo (círculos
                    concéntricos y ondas suaves).

BUG 3 — Validación inline no funcionaba (los inputs no se ponían rojos)
  Causa raíz: Mismatch entre nombres de campo. El listener buscaba IDs con el
              nombre completo ("tareas_3.2") pero el HTML los generaba con
              prefijo corto ("tar_3.2"). El campo "calificacion" -> "cal_",
              "asistencia" -> "asi_", "tareas" -> "tar_".
  Solución aplicada:
    - Mapeo en JavaScript: { calificacion: 'cal_', asistencia: 'asi_', tareas: 'tar_' }
    - Se agregaron listeners por addEventListener (no inline) a los 3 inputs
    - Se quitaron los atributos min/max del HTML para que el navegador no
      bloqueara la entrada de valores fuera de rango
    - Se agregó listener también en 'blur' para validar al salir del campo

DEBUG INSTRUMENTATION (dejar por ahora o quitar):
  - console.log('[onCambio]', campo, '=', inp.value)
  - console.warn('[render] input no encontrado:', id)
  Sugerencia: mañana quitar estos logs para limpiar consola.
